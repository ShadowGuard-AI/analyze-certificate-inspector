analyze-certificate-inspector

Inspects SSL and TLS certificates and shows their subject, issuer, validity dates, version, and serial number, with a check on whether the certificate has expired or is close to expiring.

Open the repo Usage

What it reads

  • Subject and issuer
  • Validity dates
  • Version and serial number
  • Whether the certificate has expired, or is close to expiring: the one judgement in the tool that carries a date with consequences

Install and usage

cd analyze-certificate-inspector
pip install -r requirements.txt

./analyze-certificate-inspector [params]

Dependencies are in requirements.txt: pandas and pyOpenSSL.

Parameters

-hshow help message and exit
-pno description provided in the source; the blank is left showing rather than filled with an invented duty
-venable verbose logging
-ooutput the certificate details to a CSV file
