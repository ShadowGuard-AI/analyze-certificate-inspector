First Leaf: What the Plate Records

analyze-certificate-inspector inspects SSL and TLS certificates. The leaf lists the exact fields the README lists, in its order:

  • subject
  • issuer
  • validity dates
  • version
  • serial number

Has Its Time Run Out

The tool checks whether the certificate has expired or is close to expiring. The dates matter because a certificate whose time has run out is the one finding on the plate that carries a consequence.

The project is focused on data analysis and reporting, and this leaf says that too, without adding fields, checks, or host behaviour the source never mentions.
